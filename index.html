About this table

  • Checked on {{ data.checked.date }}. Every Flisk command was checked against Flisk {{ data.checked.flisk }} with flisk --help and flisk <command> --help. A script in the repo repeats that check.
  • Every cell has a source. Flisk cells link to the Flisk source or docs. Other cells link to that tool's official documentation.
  • "No equivalent" is an answer. We do not invent a command to fill a cell. When a tool has no command for a task, the note says what you do instead.
  • Different problems stay different. Terraform provisions infrastructure. Flisk runs a local development loop. Where a Terraform command is only the nearest match, the cell says so.
  • Conflict of interest. The Flisk team maintains this page. Check the sources, and tell us when a cell is wrong.

To add a task or fix a cell, edit _data/commands.yml and run ruby scripts/check-data.rb. The README has the details.
