About

  • What it is. {{ tab_count }} tabs of commands for the same everyday jobs, with Flisk first. Each tab pairs Flisk with the tools people compare it to.
  • Checked on {{ site.data.meta.checked.date }}. Every Flisk command was run against Flisk {{ site.data.meta.checked.flisk }} with flisk <command> --help. A script in the repo repeats that check.
  • Every cell has a source. Flisk cells link to the Flisk source or docs. Other cells link to that tool's official docs.
  • Blank is an answer. We do not invent a command to fill a cell, so a tool with no command for a task is left blank. Amber commands are the closest match to a different job.
  • Pick your own. Use Pick tools to compare any set of tools. Flisk stays first, and the link keeps your picks.
  • Different problems stay different. Terraform and CDK provision infrastructure. Flisk runs a local dev loop and never deploys.
  • Conflict of interest. The Flisk team maintains this page. Check the sources and tell us when a cell is wrong.

To fix a cell or add a task, edit the YAML in _data/ and run ruby scripts/check-data.rb. The README has the details.
